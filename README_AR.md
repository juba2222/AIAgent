# 🤖 Alpha Prime - محلل الأسواق الكمي (Senior Macro Algo-Strategist)

وكيل ذكاء اصطناعي فائق التطور يعالج **14 طبقة** من البيانات الاستخباراتية لإنتاج تقارير تداول مؤسساتية قائمة على **النموذج التساعي الشامل** (Nonary Analysis Model).

---

## ⚡ البدء السريع

### 1. التثبيت
```bash
pip install -r requirements.txt
pip install -e .
```

### 2. إعداد المفاتيح
قم بضبط مفاتيح API الخاصة بك في نظام التشغيل:
```bash
export GEMINI_API_KEY="your_key"
export FRED_API_KEY="your_key"
```

### 3. تشغيل التحليل
```bash
# تحليل الذهب باستخدام قاعدة البيانات المحلية
python src/core/agent.py --asset GC=F --report full --db
```

---

## 🎯 ماذا يفعل؟
*   **التحليل التساعي الشامل:** يدمج الماكرو، نظرية المزاد (AMT)، الحسابات الكمية، والجيوسياسة.
*   **تتبع الأموال الذكية:** مراقبة تداولات أعضاء الكونجرس، تحركات الحيتان (Buffett)، والـ Dark Pools.
*   **هيكل المزاد متعدد الفترات:** تحديد مستويات POC, VAH, VAL لـ 6 فترات زمنية متداخلة.
*   **دمج الأنظمة (Regime Fusion):** التوفيق الآلي بين القراءات التقنية والكلية لمنع التناقضات.

---

## 📊 هيكلية المشروع (Repository Structure)
*   `src/core/`: العقل المركزي، المنسق، وكشف الأنظمة.
*   `src/intelligence_layers/`: طبقات الماكرو، الكوانت، والمناجم.
*   `src/amt_framework/`: تحليل المزاد وتوزيع السيولة.
*   `src/utils/`: موصلات الـ APIs (OpenBB, Tiingo, yfinance).
*   `examples/`: أمثلة تشغيلية جاهزة.
*   `data/`: أرشيف قاعدة البيانات واللقطات التاريخية.

---

## 🔬 الأبعاد التسعة للتحليل
1. **السياق الكلي:** صدمات السيولة وبيانات FRED الحقيقية.
2. **هيكل السوق:** تشخيص المزاد (توازن vs اكتشاف).
3. **هيكل السيولة:** أشكال البروفايل (P, b, D) وفراغات السيولة.
4. **تدفق الأوامر:** كشف الامتصاص والفقاعات العدوانية.
5. **المقاييس الكمية:** نماذج EWMA, VaR, و Beta الديناميكية.
6. **التحليل التقاطعي:** نسب الذهب/الفضة والضغط العكسي للدولار.
7. **التحليل الأساسي:** تقييم شركات التعدين (Piotroski/DuPont).
8. **التوليف الاستراتيجي:** بناء سيناريوهات If/Then التنفيذية.
9. **البيانات البديلة:** تتبع اللوبيات (AIPAC) والجيوسياسة.
